### 발견 문제·수정과 남은 한계

- 초기 임시 환경의 node_modules junction은 Vite가 Astro 런타임을 외부 소스로 변환하게 하여 시작 지연을 유발. 독립 물리 복사로 검증 환경 분리.
- 실제 검색 화면에서 `__VITE_PRELOAD__` 미치환 오류 발견. 빌드 후 생성되는 Pagefind import는 번들러를 거치지 않는 정적 `public/scripts/search.js`로 분리해 해결. API 호출뿐 아니라 실제 화면 회귀 검증 통과.
- 프로젝트 경로에서 검색 URL 중복 base 문제 발견. 인덱스에는 논리 경로를 저장하고 브라우저 API에 baseUrl을 한 번 적용해 해결.
- C# 태그의 Astro 출력 파일명 인코딩 차이는 안전한 태그 키 변환으로 해결.
- 한국어 UI는 직접 작성, 단어 분리는 Pagefind extended 사용. 한국어 어간 처리 없음. 여러 단어 검색의 정확한 문구 일치도 보장하지 않음: `한국어 검증`이 본문에 `검증`만 있는 글을 반환한 사례 확인. 조사/어미/띄어쓰기 일반화는 미보장.
- MDX `use astro:head-inject` 경고는 남아 있음. 경고를 숨기지 않았으며 공개 MDX 본문/이미지를 포함한 최종 빌드와 실제 정적 화면은 통과. 외부 HTTP 자산/링크 원격 가용성은 검증하지 않음.
- 증거: `.local/final-review/report.json`, 단계별 로그, 4가지 상세 스크린샷과 검색 화면. Git 제외. 임시 산출물은 배포 대상이 아님.
- 표준 명령 재확인: Node 22.23.3에서 `npm ci` 성공(취약점 0건), `npm test` **9/9 통과**, `npm run build` 성공. 실제 작업 폴더의 최종 dist는 공개 글 0개·HTML 6개 상태.
- 작성 미리보기 4321/정적 미리보기 4322 실행 후 현재 소스로 1440px light·390px dark의 7개 화면씩 **14 화면 추가 확인**, 브라우저 오류/실패 응답 없음. `.local/final-review/current-preview.json`과 current- 스크린샷 기록.
- 상태: **로컬 검증 완료 / 배포 설정 준비 완료 / 실제 공개 배포·공개 사이트 확인 미실행**. commit/push/main 반영/Pages 설정 변경/워크플로 실행 없음. 원격 기존 사이트 유지.
